# Treino Pro 💪
App de treino mobile-first (PWA) em português: musculação, calistenia, natação, HIIT, corrida e cardio.
Plano semanal automático conforme seus dias/horários, progressão de carga (dupla progressão), semanas de adaptação/deload, cronômetro de descanso, timer HIIT, recordes, histórico e coach. Tudo offline e local (sem custo de IA).

## Rodar local
`python3 -m http.server 8123` e abra http://localhost:8123

## Publicar na Vercel
Site estático, sem build. Em vercel.com → Add New Project → importe este repositório → Framework "Other" → Deploy.
No celular: abra o link → "Adicionar à tela inicial".
